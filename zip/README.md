# Zip — 一筆書きパズル

番号を 1 から順に通りながら、盤面のすべてのマスをちょうど 1 回ずつ通る一筆書きパズルです。
ライブラリなしの静的サイト（HTML / CSS / JavaScript）で、`zip/index.html` をブラウザで開くだけで遊べます。

## ルール

- 番号 **1** のマスから線を引き始める
- 線は上下左右にのみ伸び、**壁**（太い線）は通り抜けられない
- 番号は **1 → 2 → 3 …** の順にしか通れない
- 最後の番号のマスに到達したとき、盤面のすべてのマスを通っていればクリア

## 操作

| 操作 | 内容 |
| --- | --- |
| ドラッグ／スワイプ | 線を引く |
| タップ・クリック | 1 マスずつ進める |
| 引いた線を逆になぞる | そこまで線を消す |
| 矢印キー | 1 マス進める |
| Backspace | 1 手戻す |
| R | 最初から |

## 機能

- **自動生成**：難易度ごとに盤面サイズが変わり（5×5 / 6×6 / 7×7 / 8×8）、**解が一意になる問題だけ**を出題
- **今日の問題**：日付（日本時間）と難易度から seed を決めるので、同じ日なら誰が開いても同じ 4 問
- **1 日の進行**：かんたん → ふつう → むずかしい → エキスパート の順にクリアしていき、
  4 問そろうと**ランダム出題が解放**される。未解放の難易度とランダムは薄く表示され、
  押すと理由と残り問題数を案内する
- クリア画面では次にやる問題を明示（例：「本日の「ふつう」をプレイ」、4 問達成後は「ランダムで遊ぶ」）
- タイムは**問題が表示された時点**から計測。自己ベストと当日の記録は localStorage に保存
- ヒント、1 手戻す、結果のコピー、ライト／ダークテーマ
- 1 画面に収まる固定レイアウト（ページはスクロールせず、文字選択・ダブルタップ拡大も無効）

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の構造 |
| `style.css` | 配色・レイアウト（テーマは CSS 変数） |
| `engine.js` | 問題生成とソルバー（UI 非依存。Node からも読める） |
| `app.js` | 盤面描画（SVG）、入力、タイマー、記録 |
| `engine.test.js` | エンジンの自己テスト |

## 生成の仕組み

1. ランダムなハミルトン路（全マスを 1 回ずつ通る経路）を作る — Warnsdorff 法 + 連結性による枝刈り
2. その経路が使っていない辺の一部を壁にする
3. 経路上に番号を等間隔で置き、**解が一意になるまで番号を追加**する
4. 一意性を保てる範囲で番号を間引く（難易度が高いほど番号が少ない）

解の数え上げ（`countSolutions`）は、未訪問マスの連結性・行き止まりの数・番号の順序で枝刈りしながら
最大 2 通り見つかった時点で打ち切ります。

## テスト

```sh
node zip/engine.test.js
```

各難易度で 10 問生成し、「保持している解答がルールを満たすこと」「解がちょうど 1 通りであること」を検証します。
