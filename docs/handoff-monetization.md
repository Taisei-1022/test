# 申し送り：Vappa のマネタイズ（収益化）の検討

別セッションで並行して検討してもらうための引き継ぎ。**このセッションの仕事は「検討して決める」ところまで**。アプリのコードやサーバーは触らない（実装は本体のセッションで行う）。

## 1. プロダクトの現状（2026-10-04 時点）
- **Vappa（https://vappa.app/arcade/）**：AIと会話するだけで、スマホ用のミニゲームを作って公開・共有できる PWA（アプリストアを通さない＝ストアの手数料はかからない）。
- **方向性：**「送り合うくそげー」。くだらないけど、つい友だちに「この点数抜ける？」と送りたくなるゲームを、作って送り合う場所。
- **機能：**
  - 遊ぶ（ログイン不要）
  - 作る（Googleログイン必須・@IDと表示名）
  - 公開、ランキング、挑戦状（点数つきリンクを送る）
  - いいね（いつ・誰が・どのゲームにを記録済み）
  - 作者ページとフォロー、検索、通報、運営管理画面
- **ユーザー：** まだ広めていない段階。運営者は「収益の入り口がない状態では広める動機がない」と考えている。
- **賑わい演出：** ランキングやいいね数には、運営が用意した「さくら」のアカウント（30人）の記録が混ざっている。有料の「目立たせる」機能などを設計する時は、偽の人気で判断を誘っていると見られないか（景品表示法、ステルスマーケティング規制の考え方）に注意すること。

## 2. これまでに決まっている方針
- **作るのは無料。** 「盛る・目立たせる・カスタム」にお金を払ってもらう形にする（細部は未定）。
- **有料の「盛る」の候補：** 高性能なAI（Anthropic の Opus など）で作る／作り直す。無料は DeepSeek で作る。
- **決済：** Stripe を使う予定。契約の名義（個人か、知人「高井」の会社名義か）を相談中。既に審査を通っているアカウントが使えるなら、それを使いたい。
- **AdSense：**「有用性の低いコンテンツ」で不合格になり、対策を入れて再申請の準備中。広告は補助の収入という位置づけ。

## 3. 費用の実績（原価の参考）
| 中身 | 1本あたりの原価（目安） |
|---|---|
| 普通のゲームを作る（DeepSeek Flash・思考high） | 約¥2〜4 |
| 盛りまくりのゲームを作る（同） | 約¥4（上限を広げた版で¥5〜6、2段階で作る版で約¥8） |
| DeepSeek Pro で作る | 普通 約¥7、盛りまくり ¥15〜25 |
| Opus で作る | 普通 約¥40、盛りまくり 約¥80 |
| 相談（チャット1往復） | ほぼ¥0 |

- DeepSeek は、平日の昼（日本時間 10〜13時・15〜19時）は約2倍、それ以外は半額。
- サーバー（Supabase Pro）は月 $25。
- 1日の作成上限：1人15本、全体250本（コストの守り）。

## 4. 法律・決済まわりで分かっていること
- **ポイント（先に買って後で使う）：** 資金決済法の「前払式支払手段」に当たりうる。未使用の残高が基準日（3月末・9月末）に1,000万円を超えると届け出が必要。**有効期限6か月以内のポイント**、または**機能を直接売る形**なら対象外。
- **特定商取引法の表記：** 有料にするなら必須。個人の場合、住所・電話は「請求があれば遅滞なく開示」と書く形も認められている。
- **Stripe の手数料：** 国内カードで 3.6%。
- **注意：** ここに書いた法律の話は一般的な整理。最終判断の前に専門家に確認すること。

## 5. このセッションでやってほしいこと
1. **売るものの案を出す**（3〜5案）。それぞれについて次を書く：
   - 中身と値段
   - 原価と粗利
   - ユーザーが払いたくなる理由
   - 「送り合う」体験と合うか
   - 法律面の注意
   - 例：作品を1週間目立たせる／Opusで作り直す（盛る）／作成上限を増やす／見た目のカスタム（テーマ・称号）／挑戦状の演出の強化 など
2. **収益の試算：** ユーザー数と課金率の仮定を置いて、月の売上・原価・利益を出す。
   - 以前、収益シミュレーター（`arcade/sim.html`）を作ってあるので参考にしてよい。
3. **最初に出す1つ（MVP）の推薦：** 実装の手間（Stripe の組み込み、ログイン済みの仕組みとの連携）も考えて選ぶ。
4. **Stripe の名義を決めるための論点整理：** 個人か会社か、それぞれの手間・税金・審査・特商法の表記の違い。
- 成果物は `docs/monetization/` に置く。運営者に見せる時は、見やすいページ（Artifact）にまとめる。
