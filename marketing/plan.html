Vappa 発信計画（たたき台）

ショート動画とSNSで、「送り合うくそげー」の場所として知ってもらうための計画です。数字はまだ仮で、最初の2週間の結果を見て決め直します。

2026年10月4日 作成対象：2026年10月〜2027年10月数字はすべて仮

要点

  1. 一番大事にする数字は「1週間に送られた挑戦状の数」。見られた回数より、遊んで友だちに送ってもらえたかを見る。
  2. 媒体は TikTok（主役）・YouTube ショート・X の3つ。同じ動画を3か所に出す。
  3. 最初の12週間は「当たる型」を探す期間。動画は週3本、X は1日1回。
  4. 動画はこちら（Claude）がまとめて作り、投稿は手で行う。週1回30分のふり返りで、次の週に変えることを1つだけ決める。

目標

いちばん大事な数字
1週間に送られた挑戦状の数

見られる → 遊ぶ → 友だちに送る → 友だちも遊ぶ、の輪が回っているかを1つの数字で表せるため。再生数やフォロワー数は、この数字を増やすための途中の数字として見ます。

短期｜〜2026年12月末（12週間）

続けられる形と、当たる型を見つける

  • 動画を 36本 出す（週3本）
  • 再生 1万回 を超える動画が 1本 出る
  • 3媒体のフォロワー合計 1,000人
  • SNSから来て遊ぶ人 週300人
  • 挑戦状 週50件
中期｜〜2027年3月末

当たる型を増やして、勢いをつける

  • 再生 10万回 を超える動画が出る
  • 3媒体のフォロワー合計 5,000人
  • 挑戦状 週300件
  • ユーザーが作るゲーム 月100本
  • アプリ内の「プレイ動画を保存・共有」が使える
長期｜〜2027年10月（1年）

「送り合うくそげー」の場所として知られる

  • 毎週遊ぶ人 1万人
  • 挑戦状 週3,000件
  • ユーザーが自分で動画を投稿してくれる（運営以外の発信が半分以上）
  • 有料の「盛る・目立たせる」機能で売上が立つ

いまの実際の数字（来訪数・挑戦状の数）がまだわからないため、上の数字は目安です。最初の2週間で今の数字を測り、10月末に決め直します。

見てもらってから広まるまでの流れ

どこで止まっているかがわかれば、直す場所もわかります。ふり返りでは、この6つの段のどこで人が減っているかを見ます。

① 見る動画が流れてくる
② 気になる最後まで見る・プロフィールを開く
③ 来るvappa.app を開く
④ 遊ぶ1回ゲームをする
⑤ 送る挑戦状を友だちに送る
⑥ 広まる友だちが遊んで、また送る

①〜③は各SNSの「分析」画面で見られます。③〜⑥はアプリ側の数字なので、測り方を本体のセッションと相談します（下の「数字の取り方」）。

媒体と役割

媒体役割出すもの頻度
TikTok 主役知らない人に見つけてもらう。中高生〜20代が多く、「友だちと張り合う」が刺さりやすいショート動画（全種類）週3本

広告費は使わない前提です。動画が1本当たったら、その動画にだけ少額の広告をかけるかを相談します。

出すもの（5つの型）

型中身例作る手間
A. この点数抜ける？公式ゲームの自動プレイ。崩れる・負けるなど笑える瞬間で終わる動画1本目（バーガー8段）少ない（ほぼ自動）
B. 張り合い物語作る → 挑戦状 → 友だちに超えられる、の短いお話動画2本目中くらい（文言を決めるだけ）
C. 頼んでみた変なお題をAIに頼んで、本当にできたゲームを遊ぶ「上司から逃げるゲーム作って」中くらい（実際に作る）
D. 今日のくそげーユーザーが作ったゲームの紹介（作者のOKをもらってから）「◯◯さんの『◯◯』。開始3秒で負けた」少ない
E. 今週の記録ランキング上位、運営に勝った人の紹介「今週の最高は23段。人間ですか？」少ない

A 40%
B 25%
C 25%
D・E

D と E は、ユーザーの作品や記録が増えてから比率を上げます。どの型を増やすかは、ふり返りで決めます。

投稿する時間は夜19〜22時（平日）が基本です。ふり返りの数字を見て、昼12時台と比べます。投稿後1時間はコメントに返事をします（1日5〜10分）。

ふり返りの回し方（計画 → 実行 → 確認 → 改善）

計画

月曜。今週ためすことを1つだけ決める（例：冒頭の字幕を質問にする）。

実行

動画3本と X の投稿。ためすこと以外は変えない。

確認

翌週の月曜に、下の記録表に数字を書く（投稿から3日後の数字で比べる）。

改善

よかったら続ける、だめならやめる。結果を1行で残す。

週ごとのふり返りに加えて、月末に1回、型ごとの成績を並べて、翌月の配分を決めます。

記録する数字（投稿1本ごと）

数字どこで見るかわかること
再生数各SNSの分析画面①見られたか
最後まで見た割合TikTok・YouTube の分析画面②中身がおもしろかったか
保存・シェア数各SNSの分析画面②人に見せたくなったか
プロフィールを見た数・リンクを押した数各SNSの分析画面③来てくれたか
SNSから来た人・遊んだ人アプリ側（相談）③④
挑戦状の数アプリ側（相談）⑤送ってくれたか

数字を見て直す場所

こうなっていたら止まっている段次にためすこと
再生がすぐ止まる（最初の2秒で離れる）① → ②最初の1秒を変える。字幕を質問にする、いきなり崩れる場面から始める
最後まで見られるのに、プロフィールが見られない② → ③締めを変える。「点数」をもっと大きく、「抜けたらコメントで」と呼びかける
リンクは押されるのに、遊ばれない③ → ④動画と同じゲームに直接つながるリンクにする。開いた画面がわかりにくければ本体のセッションに相談
遊ばれるのに、挑戦状が送られない④ → ⑤本体のセッションに相談（結果画面の見せ方など）。動画では「送り合う」場面を増やす（型B）
どれも伸びない週が2週続く全体型の配分を大きく変える。ほかのアカウントで伸びている動画を10本見て、まねできる点を探す

数字の取り方（準備）

  • 各SNSのアカウントを「ビジネス用（プロ）アカウント」にする。無料で分析画面が見られるようになります。
  • プロフィールのリンクを媒体ごとに変える（例：vappa.app/arcade/?from=tiktok）。どこから来たかを区別するためです。
  • この印をアプリ側で数えられるか、挑戦状の数を週ごとに見られるかは、本体のセッションへの相談事項です（ここではアプリに触りません）。
  • 記録表はスプレッドシート1枚で十分です。必要なら作ります。

  • 12月末：12週間のまとめと、1〜3月の計画

守ること

  • 音楽は自作か、各アプリの中で選べる曲だけを使う。
  • ユーザーの作品や名前は、本人のOKをもらってから出す。
  • 作り物の場面（トーク画面など）には「※画面はイメージです」を入れる。生成にかかる時間はごまかさない。
  • 他社の名前・ロゴ・キャラクターを使わない。似せた作品も紹介しない。
  • 人に宣伝をお願いするときは、投稿に「PR」と書いてもらう（ステマ規制）。
  • 自動いいね・自動フォロー・自動投稿はしない。

決めてほしいこと

1. 目標の数字上の数字は目安です。高すぎる・低すぎるところがあれば教えてください。
2. 使える時間投稿とコメント返しで、1日10〜15分＋週1回のふり返り30分を想定しています。
3. Instagram1月から同じ動画を置くかどうか。
4. アカウント名3媒体で同じ名前（例：「Vappa｜送り合うくそげー」）にするか。
5. アプリ側の数字媒体ごとの来訪数と挑戦状の数を見られるようにする件を、本体のセッションに頼んでよいか。
