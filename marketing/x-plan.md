# X（旧Twitter）の運用方針（案）

## 目的
「くだらないけど、つい友だちに送りたくなるゲーム」がある場所として覚えてもらうこと。
フォロワー数より、**リンクを踏んで1回遊んでもらうこと**と、**遊んだ人が挑戦状を送ってくれること**を大事にします。

## アカウントの見せ方
- 名前：`Vappa｜送り合うくそげー`
- 自己紹介：`AIと話すだけでスマホのミニゲームが作れる。作ったら友だちに挑戦状を送ろう。毎日くそげー更新中` ＋ https://vappa.app/arcade/
- 固定ポスト：一番伸びた動画（最初はバーガータワーの動画）。

## 投稿の型（5つ）

| 型 | 中身 | 例 |
|---|---|---|
| ① 挑戦状 | ゲームの動画か画像＋運営の点数。「この点数抜ける？」 | 「バーガー8段。抜ける？👇」 |
| ② 作ってみた | AIとの会話 → 完成 → 遊ぶ様子（画面の録画やスクショ3枚） | 「『満員電車から降りるゲーム』って頼んだらこうなった」 |
| ③ 今日の1本 | ユーザーが作ったゲームの紹介（作者さんの名前を出して、事前にOKをもらう） | 「今日のくそげー：◯◯さんの『◯◯』。開始3秒で負けました」 |
| ④ 結果まとめ | 週ごとのランキング上位、挑戦状のやりとり | 「今週のバーガータワー最高記録は23段。人間ですか？」 |
| ⑤ 中の人 | 作っている裏側、新しい機能、失敗談 | 「AIに作らせたら全部ハンバーガーが空を飛んだ」 |

- 基本は ①と② で半分以上。③④⑤は合間に入れる。
- **毎回リンクを入れない**。リンクありの投稿は表示が減りやすいので、リンクは「① 挑戦状」と週1回の宣伝だけにして、ほかはプロフィールに誘導します。
- 文字は短く。1文目で何のゲームかわかるように。ハッシュタグは0〜2個（`#くそげー` を定番に）。

## 頻度（無理なく続く量）
- **1日1回**（平日の夜 19〜22時か、お昼 12時台）。
- 動画は **週2〜3本**（TikTok・YouTube ショートと同じものを使い回す）。残りの日は画像か文字だけの投稿。
- 反応してくれた人への返信・引用は毎日5分だけ見る。
- 週1回の振り返り：表示回数・リンクのクリック数が多かった投稿の「型」を数える → 次の週はその型を増やす。

## 1週間の例
| 曜日 | 型 | 内容 |
|---|---|---|
| 月 | ① 挑戦状（動画） | 公式ゲームの自動プレイ動画 |
| 火 | ③ 今日の1本 | ユーザー作品の紹介 |
| 水 | ② 作ってみた（動画） | AIに頼んでゲームを作る様子 |
| 木 | ⑤ 中の人 | 新機能・裏話 |
| 金 | ① 挑戦状（動画） | 別の公式ゲームの動画 |
| 土 | ④ 結果まとめ | 今週の最高記録 |
| 日 | 休み or ③ | |

## 気をつけること
- ユーザーの作品や名前を出すときは、先に本人のOKをもらう。
- 他社のキャラクター・ゲームに似せた作品は紹介しない。
- 炎上しやすい話題（政治・事件など）にはふれない。
- 他の人の投稿への自動いいね・自動フォローはしない（凍結されることがあります）。
